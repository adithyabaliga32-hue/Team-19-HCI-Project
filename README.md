# Team-19-HCI-Project

## iPhone app template

A starter iPhone app built with SwiftUI.

## Preview on Windows

Open `preview/index.html` in a browser to see an interactive iPhone-shaped preview. Edit that file in VS Code and refresh the browser to see your changes. This is a web mockup for designing the screen, not Apple's iOS Simulator or a native iPhone app.

## Open the template

On a Mac with Xcode installed, open `Team19HCI.xcodeproj`, choose an iPhone simulator, and press **Run**. The project targets iOS 17 and later and uses no external packages.

The sample screen is in `Team19HCIApp/ContentView.swift`. Replace its content with your team's app experience; `Team19HCIApp/Team19HCIApp.swift` is the application entry point.

Xcode and the iOS Simulator are available on macOS, not Windows.
